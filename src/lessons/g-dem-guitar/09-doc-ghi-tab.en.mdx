Learn a great line and don't write it down, and a few days later it is gone. **Tab** (tablature) is the notation guitarists know best: no reading notes on a staff, just **which string, which fret**.

## How to read tab

- **6 lines = 6 strings.** The **top line is string 1** (high E), the bottom line is string 6 — upside down compared with looking down at the neck, but the way a listener in front of you sees it.
- **Numbers = frets.** `0` is the open string, `5` is the 5th fret.
- **Read from left to right.** Numbers stacked in one column are played together (a chord or a double stop).

Tab on the internet usually **has no rhythm**: you have to listen to the record to know which notes are long or short. Tab in this app comes with a standard staff above it — stems, flags and rests show the durations. In **Tab only** view, the stems and flags are drawn right under the numbers.

## Technique symbols

| Symbol | Name | How to play it |
|---|---|---|
| `5h7` | Hammer-on | Pick fret 5, then **hammer** a finger onto fret 7 — no second pick |
| `7p5` | Pull-off | Fretting 7, **pull** the finger off so fret 5 sounds — no second pick |
| `5/7`, `7\5` | Slide | Pick, then **slide** the finger along the string to the new fret |
| `7b9`, full | Whole-step bend | Push the string until the note rises **a whole step** (2 frets) |
| `7b8`, ½ | Half-step bend | Push the string until the note rises **a half step** |
| `~` | Vibrato | Shake the finger so the note sings |
| `x` | Dead note | Touch the string lightly so it is muted and pick a percussive "tick" |
| P.M. | Palm mute | Rest the edge of the picking hand on the strings by the bridge |
| `<12>` | Natural harmonic | Touch the string right above fret 12, pick, then lift the finger |
