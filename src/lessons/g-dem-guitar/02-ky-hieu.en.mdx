Every rhythm in the app is written on a **rhythm grid**: each column is one step (using the counting from the previous lesson), and each row is one thing your picking hand does.

## Strumming symbols

| Symbol | Meaning | How |
|---|---|---|
| ↓ | Downstroke | Sweep from the low strings (string 6) towards the high strings |
| ↑ | Upstroke | Sweep up from string 1, usually only the top 3 – 4 strings |
| small ↓ / ↑ | Light stroke | Just brush a few high strings, quietly |
| ✕ | Mute (chop) | Strum down and immediately **press your palm** onto the strings — a short "chk" sound |
| (blank) | Rest | Your hand still moves but doesn't touch the strings |

## Picking symbols

| Symbol | Meaning | Finger |
|---|---|---|
| B | Bass note (the chord's root) | Thumb |
| B′ | Alternate bass (usually the 5th) | Thumb |
| 3 / 2 / 1 | Strings 3, 2, 1 | Index / middle / ring |
| B+1, 123 | Several notes together | |

<PatternView pattern="B 3 2 3 1 3 2 3" caption="Ballad picking: bass, then strings 3 – 2 – 3 – 1 – 3 – 2 – 3" />

<Callout type="note" title="One finger per string">
When picking, assign fingers permanently: the **thumb** takes the three bass strings, the **index** string 3, the **middle** string 2 and the **ring** finger string 1. Your hand no longer has to "find" strings — you only need to think about the rhythm.
</Callout>

## The bass note of each chord

To pick, or to play rhythms with a bass note (Waltz, Bolero, Foxtrot…), you need to know **which string the bass is on** for each chord. The bass is the chord's **root** on the lowest possible string; the alternate bass is usually the **5th**.

| Chord | Bass (B) | Alternate bass (B′) |
|---|---|---|
| C | String 5 fret 3 (C) | String 4 fret 2 (E) |
| Am | Open string 5 (A) | String 4 fret 2 (E) |
| G | String 6 fret 3 (G) | Open string 4 (D) |
| Em | Open string 6 (E) | String 5 fret 2 (B) |
| D, Dm | Open string 4 (D) | Open string 5 (A) |
| F | String 6 fret 1 (F) | String 5 fret 3 (C) |
| E | Open string 6 (E) | String 5 fret 2 (B) |
| A | Open string 5 (A) | String 4 fret 2 (E) |

<Callout type="tip" title="A memory aid">
Chords with their root on string 6 (G, E, Em, F) have the alternate bass on string 4 or 5. Chords rooted on string 5 (C, A, Am) have it on string 4. Chords rooted on string 4 (D, Dm) use the open 5th string.
</Callout>

For each of C, Am, G, Em and D: play only B then B′ over and over with your thumb, one note per beat, until you no longer need to look at your hand. This is the "skeleton" of every picking pattern and every rhythm with a bass line.
